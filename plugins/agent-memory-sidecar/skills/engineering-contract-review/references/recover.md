# 执行、外部效果与恢复

只读取与当前任务的真实触发、结果和约束相关的条目；下列方法不要求运行全部验证，也不授予外部写入权限。

## 按真实依赖保留有效计划与成果

适用：收到广域变更信号或恢复长任务，需要判断已有计划与成果有效性时。

执行：分别核对计划、成果的身份、依赖和授权，匹配证据直接复用；广域信号先按具名依赖判断影响。相关变化或有效性未证时，在安全边界停旧队列并按当前authority重判受影响剩余工作；保留未受影响的有效发布、成果和仍有效的获批计划。

例外：版本本身就是完整业务authority时依其契约；无错误停止或重复效果且重算廉价时可直接重算。计划仍有效不额外重算；无成果、身份不可证或契约要求原子重做时不复用成果。

## 用户结果契约不要锁死为某条命令

适用：既定实现手段失效、出现病理延迟，或准备把本地步骤写成通用义务时。

执行：区分用户要求的结果、范围、外部效果与恢复边界和实现手段；仅在这些约束及必要性能均等价时替换手段，并保留会改变结果的语义。

例外：用户明确要求该命令本身作为产物，或它是具名安全边界时不得替换；执行策略拒绝不能通过换通道绕过。

## 辅助故障、业务提交和必需清理分层

适用：辅助能力不可用，或业务已不可变提交后发生清理、诊断异常时。

执行：判断故障是否影响主结果身份、完整性或必要安全准入；非必要辅助故障只撤受影响能力，已授权独立主链继续。提交已证且无结果反证时保留业务成功、证据和计算首因，不因清理重做业务。必需清理失败另报回收阻断和唯一恢复动作，阻断所属整体验收；诊断服从实际接收方成功/失败语义。

例外：主身份/输出/安全受损不能按附属故障放行；提交未完成、结果被真实反证或清理为原子提交前置不能预留成功。非必需维护不增加整体门；stdout/stderr名称不保证跨宿主安全。

## 自有外部资源按安全终态回收

适用：创建或收口具有外部任务、进程树或临时存储效果的验证操作时。

执行：从创建起绑定准确操作、完整资源集合与所有权，让成功、失败、超时、取消、异常和未生效路径都进入终态回收。核对实际停止、活跃引用、锁及发布/回滚状态，安全后读回全部自有活任务、进程与临时根按契约收口。保存可得紧凑证据和原失败记录；证据缺口本身不拥有重数据保留权。

例外：获批持久资源按生命周期交接。执行未停、归属/引用未知、锁或发布回滚未闭合、资源仍为恢复必需时保持并报准确阻断；他人资源不删，拒绝不能换通道绕过。

## 观察事件不能接管运行与聚合终态

适用：用事件、通知、仪表或子任务状态推导聚合运行状态时。

执行：从唯一运行Owner重读当前事实，事件只触发观察，不拥有重试、取消或业务结果。判定或封存聚合终态时核对完整预期集合和真实停止边界，不能凭暂时完成或局部数量终结；运行中可展示准确标明覆盖范围的观察。观察失败单独报告，不暗中扩展控制流程或观察预算。

例外：稳定封闭且已核对完整集合的原生终态可直接消费；普通进度观察无需等待整个运行停止；已授权控制组件按原有职责操作。

## 不可变发布源与运行写入必须分离

适用：运行将消费契约声明不可变的发布源、定义或内容寻址包时。

执行：将所有运行产生的可变数据路由到准确拥有的运行工作区；在实际进程边界落实写入约束，并在声称本次运行符合不可变契约前核对源身份前后一致。发现变化时撤销准确受影响运行与候选资格，保留反证并路由源污染修复。

例外：本次任务明确授权修改开发源，或该对象契约本来可变时，不套用不可变运行规则；已有匹配且覆盖实际写入边界的证据可以复用，不要求无风险热路径每次全量hash。

## 围绕批准用户结果连续推进

适用：为同一已批准切片选择下一步或推进确定性修复、验证和恢复时。

执行：按当前用户结果及最早未证消费者选下一步，分层报告文档、实现、行为和用户结果；在批准事实层、效果和硬边界内连续推进等价步骤，不逐命令再问。零效果失败不冒充已消费效果预算；非阻塞验证债仅真实失败、身份失效、直接阻断或晋级门触发才抢占。预算到界、范围/契约/风险变、影响授权/资格的反证及人类决定出现时停依赖动作。

例外：批准研究/控制维护/基础设施时按该产物推进。逐步确认、效果已发生但结果未知、人类专属提交/隐私/判断仍保留；不得把实现授权扩大到发布/外部写，已触发安全发布门不得跳过。

## 冻结外部操作并按提交状态恢复

适用：执行或恢复有外部创建/更新效果的同一操作，或发布以完成标记开放的多内容结果时。

执行：冻结业务身份、目标及幂等键，发现元数据向原authority核验；在途路由不改绑、不覆盖他物、不建副本。多内容发布隔离候选，真实生产结束且必需内容验证后最后公开完成标记；提交前失败保留旧可见集合并按原事务恢复已改写。效果/提交/回滚未知时用可信对账或已有幂等收敛，不盲目重生产；已提交后清理独立处理，不改业务成功。

例外：确未提交且安全才按授权重试；新对象须属明确允许或获批新业务操作。无可靠对账/幂等报未知。合法部分可见按各自边界，原生原子足够不造事务层，未引用不可变对象不必立即删。
