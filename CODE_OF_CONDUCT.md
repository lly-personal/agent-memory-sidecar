# Code of Conduct

We expect project participation to be respectful, specific, and focused on improving the work.

- Discuss ideas and evidence, not personal attributes.
- Assume good faith while still asking for reproducible facts.
- Do not publish private prompts, rules, credentials, filesystem paths, or security reports.
- Avoid harassment, threats, discrimination, sexualized content, and sustained disruption.
- Respect maintainers' decisions about scope, safety, release timing, and disclosure.

Report conduct concerns privately through the repository owner's GitHub contact channel. Maintainers may edit or remove content,
limit participation, or ban accounts when needed to protect contributors and users. Enforcement should be proportionate, documented
to the affected participant when practical, and must not expose a reporter's private information.
