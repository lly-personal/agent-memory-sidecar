# Support

Agent Memory Sidecar is an experimental open-source project without a commercial support commitment.

- Use GitHub issues for reproducible non-security bugs and bounded feature requests.
- Use GitHub private vulnerability reporting for security issues; follow `SECURITY.md`.
- Include the released version, operating system, Python version, entrypoint, and a minimal sanitized reproduction.
- Do not attach Store files, Hook configuration, prompt text, private rules, credentials, personal paths, or task IDs.

Only the latest published release is supported. Source snapshots, private engineering deployments, historical tags, host automation,
model adoption, and user-specific Global Owner repositories are outside public support unless a maintainer explicitly says otherwise.
