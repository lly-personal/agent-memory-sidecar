# 独立评分与回归边界

执行者只读 sources.md 和随后读取的 owner.md，不读取本文件。评分者在执行者冻结输出后打开本文件。
这是能力评估及人工校准材料，结构单元测试不能代替它；不作为自然任务采用或生产资格证据。

必查语义，每项记录 found / missed / wrong 及对应源引用，允许合理合并或拆分卡片，不按数量评分：

- alpha：变化信号只触发检查；准确依赖相关性才支持失效。保留完整输入版本及依赖未知的例外。
- beta：保存可验证结果，重新计算恢复决策；保留冻结输入的确定性续跑例外。
- gamma：已提交结果与清理阻断分层，不能因清理失败诱导重复提交。可整合 result-layers，但不能只写成已有覆盖而丢失提交/清理边界。
- delta：真实生产者连到消费者并验证共享状态迁移；可整合 real-entry，但既有纵向切片不自动覆盖这个增量。
- epsilon：已被 result-layers 精确覆盖；不得再新增近义全局规则。
- zeta：固定颜色数量与材质参数属于项目，不得全局化。
- eta：恢复或替代路径验收须证明该路径实际接续，不能让仍健康的正常路径代为完成；保留自然故障已有准确归因时无需额外注入的例外。普通真实入口切片并不自动覆盖这个增量。

另查：三十天外的活动来源仍被使用；每节均有去向；E2不要求第二项目；事实与推断有区别；无答案泄漏；
不因缺少 Session 就删除其他独立证据。关键语义正确后，用同一份模型结果通过 Project/Review Pack 校验、
确定性渲染、可见字节校验与 task-artifact 读回，验证下游未丢失发现。

验收目标：上述明确标注语义全部有正确去向且无错误全局化。此目标只属于固定小样本，不能外推为任意工程
百分之百召回。持有相反材料的新样本应独立加入，不向执行提示添加候选答案。

后续真实任务采用还需：源与规则作用域对应、已批准规则实际加载、适用任务行为改变、不适用反例未被误约束，
撤销后新任务不再沿用该 Owner。报告重复纠正次数、误约束和新增操作成本，不能用卡片数或格式通过替代收益。

真实场景、完整行为链、体验与心智模型的验收以
[真实用户旅程验收](../../../../../docs/specs/interface.md#真实用户旅程验收)为唯一规范。
本样本即使全部通过，也不具备该旅程的通过资格。评分者须将固定语义结果与真实用户旅程分别记录；
对用户未能找到结果、误解作用域或生效状态、被要求重复说明/确认、无法完成拒绝或撤销的情况，
保留准确阻断与证据，不以结构校验或模型自评替代真实使用观察。
